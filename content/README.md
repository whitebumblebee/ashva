# Local content snapshots

See [pipeline, source rights and measured coverage](../docs/CONTENT_PIPELINE.md).

`raw/` preserves the pinned source exports; `packs/` contains versioned derived data, not app-installed lessons. Do not edit generated data, overwrite different pack bytes, drop attribution, or replace the snapshot lock to bypass a failed verification.

Opening taxonomy: CC0-1.0. Broadcast export and derived game data: CC-BY-SA-4.0. Source evidence, changes and credits travel with each manifest and `ATTRIBUTION.txt`; these collections do not share one blanket license.
